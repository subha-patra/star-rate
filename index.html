Documentation and live examples v1.0.0

star-rate

A framework-agnostic rating UI for JavaScript, Angular, React, Vue, Web Components, and static HTML.

Download & install

Install the universal rating package. It has no Angular, React, or Vue runtime dependency.

Terminal
npm install star-rate

Usage

Use the root import for JavaScript APIs, or register the Web Component for HTML usage.

JavaScript / TypeScript
import { starRate } from 'star-rate';

const rating = starRate.create('#rating', {
  value: 3.5,
  max: 5,
  precision: 0.5,
  icon: 'star',
  onChange: value => console.log(value)
});
Web Component
<form id="review-form">
  <star-rate
    name="rating"
    theme="bootstrap"
    labels="Poor,Fair,Good,Very good,Excellent"
    show-label
    required
    clearable
    error-text="Please select a rating"
  ></star-rate>

  <button type="submit">Submit review</button>
</form>

Registered Web Components are form-associated through ElementInternals when supported. Older browsers and starRate.create() DOM instances keep the hidden-input fallback.

Integrations

The same root import works in framework event/mount lifecycle code.

Angular
Angular
import { afterNextRender, Component } from '@angular/core';
import { starRate } from 'star-rate';

@Component({ template: '<div id="rating"></div>' })
export class RatingComponent {
  constructor() {
    afterNextRender(() => starRate.create('#rating', { value: 4 }));
  }
}
React
React
import { useEffect, useRef } from 'react';
import { starRate } from 'star-rate';

export function Rating() {
  const ref = useRef(null);
  useEffect(() => {
    if (!ref.current) return;
    const rating = starRate.create(ref.current, { value: 4 });
    return () => rating.destroy();
  }, []);
  return <div ref={ref} />;
}
Vue
Vue

</script>

<template><div ref="target" /></template>

Mobile & native

Use the DOM renderer for mobile web, Ionic, Capacitor, and Cordova. Use the headless helpers for React Native renderers.

Mobile web touch support

The DOM renderer uses Pointer Events, so tap and drag work across mouse, touch, pen, Ionic, Capacitor, and Cordova webviews.

Mobile web touch support
import { starRate } from 'star-rate';

starRate.create('#rating', {
  value: 3.5,
  max: 5,
  precision: 0.5
});
Ionic Angular

Create the rating after the view renders, the same way you would initialize any DOM widget inside an Ionic page.

Ionic Angular
import { afterNextRender, Component } from '@angular/core';
import { starRate } from 'star-rate';

@Component({
  template: '<ion-item><div id="rating"></div></ion-item>'
})
export class RatingPage {
  constructor() {
    afterNextRender(() => starRate.create('#rating', { value: 4 }));
  }
}
Ionic React

Use a ref inside Ionic React and destroy the instance when the component unmounts.

Ionic React
import { IonItem } from '@ionic/react';
import { useEffect, useRef } from 'react';
import { starRate } from 'star-rate';

export function RatingItem() {
  const ref = useRef<HTMLDivElement | null>(null);
  useEffect(() => {
    if (!ref.current) return;
    const rating = starRate.create(ref.current, { value: 4 });
    return () => rating.destroy();
  }, []);
  return <IonItem><div ref={ref} /></IonItem>;
}
React Native headless

React Native does not render DOM nodes, so use the headless value helper with Pressable, Text, or SVG components.

React Native headless
import { Pressable } from 'react-native';
import { starRate } from 'star-rate';

const width = 160;

<Pressable
  onPress={event => {
    const value = starRate.valueFromPosition(
      event.nativeEvent.locationX,
      width,
      { max: 5, precision: 0.5 }
    );
    setRating(value);
  }}
/>;

Methods

Keep the returned instance if you need to update the rating after rendering.

MethodPurpose
setValue(value)Set the selected value and update the UI.
getValue()Read the current selected value.
update(options)Patch options and re-render.
clear()Reset the selected value to zero.
validate()Show required validation and return whether the rating is valid.
enable()Clear disabled state.
disable()Set disabled state.
focus()Focus the accessible slider control.
destroy()Remove rendered DOM from the target.
valueFromPosition(x, width, options)Headless rating value helper for React Native and custom renderers.
roundValue(value, precision)Round a value to the configured rating precision.
clampValue(value, max)Clamp a value between zero and the maximum rating.

Accessibility

Rendered ratings use role="slider", ARIA value attributes, readable labels, disabled/readonly states, and keyboard controls: Arrow keys, Home, End, Enter, and Space.

Migration from angular-star

angular-star is replaced by star-rate. Use max instead of length, precision instead of fractions, and icon instead of iconType. The aliases still work during migration.
